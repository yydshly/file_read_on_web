# 资料系统化分析

## 一、资料总体情况

当前资料目录约有 332 个文件，主要集中在两个来源：

| 一级目录 | 文件数 | 体积 | 主要格式 |
|---|---:|---:|---|
| 西安高层次人才教育类 | 297 | 约 506.95 MB | `.doc`、`.pdf`、`.docx` |
| 教基教综 | 30 | 约 43.39 MB | `.pdf`、`.doc`、`.jpg`、`.txt` |
| 知识库 | 4 | 很小 | `.md` |

结论：资料主体明显偏向“西安高层次人才教育类”，`教基教综` 更像一套相对干净的基础包。

## 二、文件格式分析

| 格式 | 数量 | 体积 | 判断 |
|---|---:|---:|---|
| `.pdf` | 146 | 约 434.93 MB | 适合阅读、打印、保留原貌，但不方便二次编辑 |
| `.doc` | 164 | 约 112.28 MB | 旧版 Word 格式，后续建议统一转换或只保留精选 |
| `.docx` | 13 | 约 1.16 MB | 适合编辑和提取文字 |
| `.jpg` | 3 | 约 1.98 MB | 多数可能是广告或扫码图，学习价值较低 |
| `.txt` | 1 | 很小 | 辅助说明 |

结论：格式统一的重点不是把所有文件都转格式，而是优先处理高价值资料。尤其 `.doc` 数量很多，不建议一开始全部转换。

## 五、主要问题

### 1. 资料太多，但主线不够明确

同一模块可能同时存在：

- 精美笔记
- 思维导图
- 讲义
- 高频考点
- 专项题
- 预测题
- 密押卷
- 答案解析

如果不先设主线，就会不断换资料，感觉一直在学，但没有形成体系。

### 2. `.doc` 旧格式太多

`.doc` 文件可以读，但不适合作为长期知识库格式。后续可以分批处理：

- 核心 `.doc` 转为 `.docx` 或提取为 Markdown
- 普通题库 `.doc` 保留原样
- 低价值押题/广告类资料不处理

### 3. 题库和答案需要配对

题库类资料多，但如果题本和答案分散，会降低刷题效率。后续整理时应优先建立：

```text
题本 -> 答案 -> 模块 -> 使用阶段
```

### 4. 职测资料是否需要投入还不能直接确定

职测/行测资料数量很多，但是否值得系统学习，要先由真题判断。如果考试中职测占比低，投入过多会稀释教综复习时间。

## 六、系统化整理建议

第一阶段不要移动原文件，先建立“索引型知识库”。

推荐结构：

```text
知识库
├─ 00_资料索引.md
├─ 01_考试画像.md
├─ 02_知识体系地图.md
├─ 03_错题与易错点.md
├─ 04_资料系统化分析.md
├─ 10_核心资料清单.md
├─ 20_教综知识框架.md
├─ 30_职测知识框架.md
└─ 40_真题分析.md
```

## 七、第一步具体怎么做

### 第 1 小步：建立资料台账

给每份重要资料打标签，而不是重命名所有文件。

建议标签：

| 标签 | 含义 |
|---|---|
| `核心` | 第一轮必须用 |
| `辅助` | 看不懂时补充 |
| `刷题` | 用于练习 |
| `答案` | 题库配套答案 |
| `冲刺` | 考前背诵、押题、口诀 |
| `暂缓` | 暂时不看 |
| `待判定` | 要等真题分析后决定 |

### 第 2 小步：先筛出核心资料

第一轮核心资料不要超过 10 份：

- 2020-2025 西安高层次真题
- 教基教综精美笔记
- 教基教综思维导图
- 教综 6000 题及答案
- 市情/省情资料

### 第 3 小步：再做格式统一

格式统一建议分三档：

| 档位 | 处理方式 |
|---|---|
| 核心资料 | 建索引，必要时转成可编辑文本 |
| 常用题库 | 保留 PDF/Word 原格式，建立题本-答案对应 |
| 边缘资料 | 不转换、不精读，只放入暂缓区 |

不要一开始全量转换。全量转换会花很多时间，但不一定提高分数。

## 八、当前推荐结论

这批资料的第一步不是重命名，也不是全部转格式，而是：

```text
先盘点 -> 再分层 -> 再建索引 -> 再筛核心 -> 最后按需统一格式
```

最优先要做的是：

1. 做一份全量资料台账。
2. 给资料打学习标签。
3. 从 300 多份文件里筛出第一轮 10 份以内的核心资料。
4. 只对核心资料做格式统一和知识提取。
