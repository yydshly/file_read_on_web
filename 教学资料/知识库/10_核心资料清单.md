# 核心资料清单

## 使用原则

第一轮不要同时打开太多资料。先用这份清单建立主线：

```text
真题定方向 -> 导图搭框架 -> 笔记学知识 -> 题库检测 -> 答案订正 -> 错题沉淀
```

这份清单不是说其他资料没用，而是先把注意力压到最值得用的一小组资料上。

| 小四门 | `教基教综/【02】教综6000题/6600题库/6600小四门部分.pdf` | `教基教综/【02】教综6000题/6600答案/6600小四门部分 答案.pdf` |

刷题方法：

```text
每次 50-100 题
先独立做
再对答案
只记录错因，不抄整题
错题回填到 03_错题与易错点.md
```

错因标签：

- 概念混淆
- 人物理论对应错误
- 关键词没记住
- 题干陷阱
- 法规条文不熟
- 做题技巧问题

## 六、第一轮暂不作为主线的资料

以下资料不是没用，而是不适合作为第一轮主线：

- 预测题
- 密押卷
- 押题卷
- 大量专项题库
- 职测/行测全部资料
- 各类“必过”“内部”“冲刺”资料

处理方式：

```text
先标为冲刺/待判定
等真题画像完成后再决定是否使用
```

## 七、第一周执行建议

### 第 1 天

- 浏览 2020-2025 真题
- 不做题，只标模块
- 填 `01_考试画像.md`

### 第 2 天

- 看教育学思维导图
- 学 `新版教育学.pdf`
- 做教育学 6000 题 50-100 题

### 第 3 天

- 继续教育学
- 整理教育学知识框架
- 复盘错题

### 第 4-5 天

- 心理学：导图 + 笔记 + 题库

### 第 6-7 天

- 教育心理学：导图 + 笔记 + 题库

## 八、最小闭环

每天只要完成这个闭环，就算有效学习：

```text
看 1 个小节
做 50 道题
记录 5 条以内真正重要的错因
回到知识框架补 1-3 条易错点
```
